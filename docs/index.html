Escribe Markdown y Quarto.
Sin distracciones.

Tigorra es un editor de escritorio nativo con vista previa instantánea, KaTeX y mhchem, corrector Hunspell, callouts de Quarto y ejecución de celdas Python con Matplotlib.

Todo lo que necesitas en un editor técnico

Sin Electron, sin navegador incrustado: un binario nativo con todo empaquetado.

Markdown real

Archivos en disco, pestañas, recientes, carpeta de trabajo y Abrir rápido con ⌘P.

Vista previa fiel

Párrafos ajustados, tablas alineadas, listas anidadas, tareas interactivas, imágenes y enlaces.

Quarto

Frontmatter YAML, callouts, chunks {python} y exportación con el CLI a HTML, PDF y DOCX.

KaTeX y mhchem

Fórmulas en línea y en bloque con tipografía STIX Two, incluidas reacciones químicas.

Ortografía

Hunspell es-ES, gl-ES y en-US, detección de idioma por documento y correcciones prudentes.

Python

Kernel persistente en segundo plano, salida en vivo, figuras inline e interrupción sin perder estado.

Deshacer completo

⌘Z cubre lo que escribes y también negritas, reemplazos y correcciones.

7 paletas

Tokyo Night, Solarized, VS Code Dark+, Catppuccin, Gruvbox y más, con 5 hojas de estilo.

Nativo y portable

Binarios para macOS arm64/Intel, Linux x86_64 y Windows, publicados en cada release.

Capturas

¿Versión web? Todavía no. Tigorra es una app nativa: lee y escribe archivos, lanza procesos de Python y usa el CLI de Quarto. Una demo en el navegador necesitaría un port a WebAssembly con esas funciones sustituidas por APIs del navegador (subir/descargar archivos) y sin ejecución de código. Es un proyecto aparte; esta página y los Releases son la vía de uso “online” por ahora.
